# Hum support

Hum is a free, open-source AAC app for Gestalt Language Processors, made by volunteers.

## Get help

- **Questions, bugs and ideas:** open an issue at <https://github.com/dsuresh-ap/hum-aac-ios/issues>.
  Please don't put your child's name, photos or recordings in an issue: issues are public.
- **Making boards with a file or a coding agent:** see the [setup guide](CONFIG.md).

## Common answers

- **Getting into the grown-up settings:** press and hold the lock button for 3 seconds (or use a
  two-finger triple tap, if you chose that in Settings).
- **Locking the device to Hum:** use Guided Access (Settings → Accessibility → Guided Access).
- **A more natural voice:** download an "Enhanced" or "Premium" voice in Settings → Accessibility →
  Spoken Content → Voices.

## Important

Hum is a communication tool. It is not a medical device or therapy, and it doesn't replace a
speech-language pathologist. Don't rely on Hum as the only way to call for help in an emergency.

Privacy: see the [privacy policy](privacy.md).
